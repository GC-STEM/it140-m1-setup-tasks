## Setup Process

> **Prepare → Install → Configure → Verify → Update**

0. **Check**: Manually check that your computer meets the system requirements for the IT 140 development environment.

1. **Prepare**: Run the bootstrap commands to download the main course repository to your local computer.

2. **Install**: Run the installation script to install the course IDE and its managed components.

3. **Configure**: Run the configuration script to configure the course IDE for your local computer.

4. **Verify**: Run the verification script to confirm that the course IDE is installed and configured correctly.

5. **Update**: Run the update script periodically to maintain or repair the course IDE and its managed components.
